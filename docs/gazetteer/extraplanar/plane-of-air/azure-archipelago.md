# The Azure Archipelago
<div class="grid cards ext-narrow-margin ext-one-column" markdown>
-    :octicons-location-24:{ .lg .middle } A floating archipelago in the [Elemental Plane of Air](<../../../cosmology/energy-realms/elemental-plane-of-air.md>), the [Energy Realms](<../../../cosmology/energy-realms/energy-realms.md>)  
</div>


The Azure Archipelago is a cluster of floating islands in the [Elemental Plane of Air](<../../../cosmology/energy-realms/elemental-plane-of-air.md>). It is described in [The Lay of Estar](<../../../things/books/the-lay-of-estar.md>) and in later reports as a set of lush, verdant islands drifting in a synchronized dance, surrounded by walls of perpetual mist.

# The Daran Garrison
:speaker:{ .middle } *(DAR-an GAIR-ih-sun)*  
<div class="grid cards ext-narrow-margin ext-one-column" markdown>
-    :octicons-location-24:{ .lg .middle } A garrison in the [Tyrwinghan Hills](<tyrwinghan-hills.md>), the [Mostreve Hills](<../mostreve-hills.md>), [Greater Sembara](<../greater-sembara.md>)  
</div>


Daran Garrison is an [Army of Mostreve](<../../../groups/sembaran-army/army-of-mostreve.md>) post near the [Daran](<../rivers/tyrwinghan-watershed/daran.md>)’s headwaters in the [Tyrwinghan Hills](<tyrwinghan-hills.md>). Together with [Maerwyn Garrison](<maerwyn-garrison.md>), it guards the gap between the hills and the [Maerwyn Mountains](<../maerwyn-mountains.md>). It houses roughly a hundred soldiers drawn from Tyrwingha’s three Guard Companies.

# The Aatmaji Dynasty
:speaker:{ .middle } *(AAT-mah-jee)*  
<div class="grid cards ext-narrow-margin ext-one-column" markdown>
-
   :octicons-info-24:{ .lg .middle } A [Dunmari](<../../gazetteer/greater-dunmar/realms/dunmar/dunmar.md>) dynasty  
</div>




The first ruling dynasty of [Dunmar](<../../gazetteer/greater-dunmar/realms/dunmar/dunmar.md>), founded by [Bhishma](<../../gods-and-religions/gods/incorporeal-gods/dunmari-pantheon/bhishma.md>). The Aatmaji dynasty ruled [Dunmar](<../../gazetteer/greater-dunmar/realms/dunmar/dunmar.md>) from DR 1173 to DR 1395, with [Kharsan](<../../gazetteer/greater-dunmar/hara-basin/kharsan.md>) as its administrative center. It ended when its last Samraat, [Dasa](<../../people/historical-figures/dunmari-rulers/dasa.md>), led a disastrous expedition into [Drankor](<../../gazetteer/drankorian-hinterland/drankor/drankor.md>) and never returned.
